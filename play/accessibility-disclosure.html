Weir – Accessibility service disclosure (Android)

This recording shows the in-app prominent disclosure Weir presents before asking the user to enable its accessibility service, the consent step, the Android Settings flow, and the service in action: when the user opens YouTube Shorts, Weir steps back out and shows its intention screen.

Weir uses Android's AccessibilityService API only to recognise the Instagram and YouTube surfaces the user asked to turn off (Reels, Explore, Shorts, Home feed). It reads layout identifiers of those two apps only; it never reads messages, passwords or any content, and nothing is stored or sent anywhere.
